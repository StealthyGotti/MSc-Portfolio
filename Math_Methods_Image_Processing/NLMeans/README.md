## Assignment: Image Denoising via Pixel-Based Non-Local Means (NL-Means)

This assignment focuses on restoring a corrupted natural image by reducing additive white Gaussian noise through the Pixel-Based Non-Local Means (NL-Means) algorithm. Unlike traditional local filters that average pixels within a tight neighborhood, the NL-Means algorithm leverages the structural redundancy of images, computing the estimate of a pixel as a weighted average of all pixels whose surrounding patches are structurally similar to the reference patch.

### Tasks Overview

* **Data Setup and Initialization**: Mount the workspace drive and load the target validation image (e.g., `cameraman.png`). Rescale its intensity range to $[0, 1]$, crop it to a sub-region to optimize computational load, and establish core spatial dimensions: the patch diameter $p = 7$ (defining a patch vector size $M = 49$) and the search neighborhood radius $H = 12$.
* **Noise Corruption Simulation**: Corrupt the pristine target image by adding zero-mean White Gaussian Noise with a standard deviation of $\sigma = 20/255$. Clip the intensity values to guarantee they remain strictly bounded within the $[0, 1]$ interval, and dynamically tune the exponential filtering parameter $h$ as a function of the noise level ($h = 10\sigma$).
* **Baseline Fidelity Evaluation**: Calculate the baseline Peak Signal-to-Noise Ratio (PSNR) of the corrupted input against the ground-truth image. Generate side-by-side visualizations displaying the original image and the noisy observation to benchmark the degradation level.
* **Boundary Padding and Pre-allocation**: Initialize an empty array $\hat{Y}$ matching the spatial dimensions of the image to store the restored outputs. Apply a reflective padding scheme to the boundary borders of the noisy image using a width of $\lfloor p/2 \rfloor$ to handle edge conditions without introducing artificial boundary seams.
* **Non-Local Search and Filtering Loop**: Run a nested spatial loop over every pixel coordinate $(i, j)$. Extract the reference patch vector, and initialize both the target pixel estimate accumulator and the partition function denominator. Search the constrained local neighborhood $(2H+1 \times 2H+1)$, compute the squared Euclidean distance between patch matrices, map this metric into an exponential similarity weight, and update the accumulators.
* **Restoration Analysis**: Normalize the accumulated pixel estimators by the total structural weight partition to yield the final denoised matrix. Compute the recovered Peak Signal-to-Noise Ratio (PSNR) and render the final processed image to assess the texturing and edge-preserving behavior of the non-local filter.
