## Assignment: Adaptive Image Restoration via 2D Local Polynomial Approximation (LPA-ICI 2D)

This assignment extends the non-parametric Local Polynomial Approximation (LPA) and Intersection of Confidence Intervals (ICI) framework to two-dimensional signals for advanced image denoising. By constructing direction-dependent 2D polynomial kernels, the algorithm adaptively selects the optimal anisotropic spatial window scale at each pixel coordinate, effectively suppressing additive Gaussian noise while successfully preserving sharp structural edges, corner primitives, and texture boundaries without inducing uniform isotropic blur.

### Tasks Overview

* **Algorithmic Parameter Setup**: Initialize the multi-dimensional framework by fixing the 2D polynomial degree $N$, defining a discrete set of spatial scale window choices $h$, setting up the direction-dependent orientation sectors, and establishing the confidence threshold multiplier $\Gamma$ to govern the statistical boundary intervals.
* **Degradation Simulation**: Load the target ground-truth natural image, normalize its intensity range to $[0, 1]$, and corrupt the pristine matrix by injecting zero-mean White Gaussian Noise with a controlled standard deviation $\sigma$. Compute and display the initial degraded Peak Signal-to-Noise Ratio (PSNR) as a baseline benchmark.
* **2D Directional LPA Kernel Construction**: Implement the mathematical routines to build two-dimensional LPA convolution kernels for each candidate scale $h$ and directional orientation. This involves generating the 2D polynomial coordinate matrices, applying directional window weighting functions, and solving the localized weighted least squares system to isolate the estimator kernels.
* **Anisotropic 2D ICI Processing Loop**: Execute the core intersection tracking routine across the 2D image coordinate space. For each pixel and within each directional sector, evaluate the sequential outputs of the 2D convolution filters, dynamically updating the overlapping statistical confidence intervals to automatically pinpoint the largest stable smoothing scale.
* **Statistical Fusion and Performance Evaluation**: Aggregate the independent direction-adaptive pixel estimations using an inverse variance fusion scheme to compile the final restored image matrix. Output comprehensive diagnostic visualizations—including the cleaned image, comparative error maps, and the spatial distribution profiles of the selected optimal scales—to validate the edge-preserving behavior of the 2D LPA-ICI protocol.
