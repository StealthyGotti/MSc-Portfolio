## Assignment: Sparse Image Denoising via Iteratively Reweighted Least Squares (IRLS)

This assignment focuses on image restoration and denoising using sparse coding over an overcomplete dictionary via the Iteratively Reweighted Least Squares (IRLS) algorithm. Instead of direct proximal mappings, this approach tackles the non-smooth $L_1$-regularized reconstruction problem by solving a sequence of smooth, weighted quadratic subproblems, where the weights are adaptively updated at each iteration based on the current sparse coefficients.

### Tasks Overview

* **Data Preparation and Noise Simulation**: Load a natural target image, normalize its intensity values, and corrupt it with additive white Gaussian noise. Define structural execution parameters, including the patch size $p$ and the sliding window stride (`STEP`) for block processing.
* **Dictionary Initialization and Patch Extraction**: Load a pre-computed or analytical overcomplete dictionary matrix $D$ from a data file. Implement a spatial loop to extract overlapping $p \times p$ patches from the corrupted image, flattening each patch into a signal vector $s$.
* **Mean Removal and Preprocessing**: For each extracted patch vector $s$, calculate and subtract its local mean $m$ to isolate the zero-mean signal components $s_{zm} = s - m$. This decoupling ensures that the sparse optimization process focuses purely on structural textural primitives rather than uniform illumination changes.
* **IRLS Core Optimization Solver**: Implement the Iteratively Reweighted Least Squares (IRLS) subroutine to minimize the $L_1$ penalty objective function for each zero-mean patch. The solver iteratively constructs a diagonal weight matrix $W$ based on the inverse magnitude of the coefficients from the previous step, transforming the sparse recovery problem into an easily solvable system of weighted linear least squares.
* **Overlapping Patch Re-projection and Aggregation**: Reconstruct the clean patch vector by mapping the optimized sparse coefficients back through the dictionary and restoring the local mean ($\hat{s} = Dx + m$). Reshape the vector back to a 2D grid and accumulate the results into a global reconstruction canvas, while simultaneously updating a secondary weight tracking matrix to account for overlapping patch redundancies.
* **Fidelity Normalization and Performance Evaluation**: Normalize the final aggregated image array by dividing it pixel-wise by the overlap counter matrix to eliminate edge block artifacts. Compute standard statistical metrics, such as the Peak Signal-to-Noise Ratio (PSNR), and render comparative visualizations to evaluate the textual preservation capabilities of the IRLS framework.
